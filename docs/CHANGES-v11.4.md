# TerminalWidget 11.4

## Neu: Position im Detail
Ein eigenes Fenster für eine einzelne Aktie:

- **Zehn Kennzahlen:** Wert, Einstand (mit Durchschnitt je Stück), Buchgewinn, Gesamtergebnis, Rendite p.a. (XIRR), realisiertes Ergebnis, Dividenden (auch letzte 12 Monate), Dividende auf den Einstand, Gebühren, Anteil im Depot
- **Je Jahr:** gekauft, verkauft, Dividenden, Gebühren
- **Je Broker:** aktuelle Stückzahl (Splits berücksichtigt), Anzahl Orders, Volumen, Gebühren
- **Alle Buchungen** der Aktie

So kommst du hin:
- Rechtsklick auf eine Zeile im Portfolio oder in der Watchlist → **Position im Detail (POS)**
- Analyse → Seite **Rendite** → Doppelklick auf eine Zeile
- Analyse → Klick auf die Kachel **Beste** oder **Schwächste Position**
- Befehlszeile: `NVDA POS`

Im Fenster kannst du direkt eine Buchung erfassen oder den Chart öffnen. Der Privat-Modus (F9) verdeckt Stückzahlen und Beträge. Beträge stehen in der Basiswährung der Analyse.

Hat eine Position keine Buchungen, zeigt das Fenster die Werte aus dem Portfolio-Editor und sagt das auch dazu.
